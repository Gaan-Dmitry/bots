# Bots

Репозиторий содержит два Lua-аддона для World of Warcraft и вспомогательную Python-панель PBot HUD.

## Состав

- `LuraBot/` — сигнальный аддон для чернокнижника.
- `PatriarchBot/` — сигнальный аддон для друида.
- `PBot_Python/` — оконная панель, считывание цветов индикаторов и отправка назначенных клавиш.

## Важно о версии WoW

Оба файла `.toc` содержат `Interface: 30300`. Это формат интерфейса клиента Wrath of the Lich King 3.3.5a, а не актуального Retail-клиента. Код использует API и названия заклинаний, рассчитанные на старый клиент/сервер. Одного изменения номера `Interface` недостаточно для переноса на другую версию: API, макросы и заклинания нужно проверять отдельно.

Установка аддона: скопируйте папку `LuraBot` или `PatriarchBot` в `World of Warcraft/Interface/AddOns/`, чтобы файл `.toc` лежал непосредственно внутри соответствующей папки. Перезапустите клиент или выполните `/reload`. В игре включите отображение устаревших аддонов, если клиент предлагает такую настройку.

## Установка PBot Python на Windows

1. Установите Python 3 с поддержкой виртуальных окружений. При наличии Python Launcher скрипт выберет `py -3`.
2. Откройте PowerShell в папке `PBot_Python`.
3. При необходимости разрешите запуск скрипта только для текущего процесса: `Set-ExecutionPolicy -Scope Process Bypass`.
4. Выполните `./setup.ps1`. Он создаст локальное окружение `.venv` и установит зависимости из `requirements.txt`.
5. Для первого запуска используйте `./run_bot_debug.ps1`, а не скрытый лаунчер. Ошибки будут видны в консоли и сохранятся в `PBot_Python/logs/`.
6. Когда приложение запускается без ошибок, можно использовать `./run_bot.ps1` для скрытого запуска.

Если игра запущена с повышенными правами, Windows может ограничить взаимодействие с ней из процесса без таких же прав. Для диагностики запускайте PowerShell с тем же уровнем прав, что и клиент игры.

## Быстрая диагностика

- Если появилось `ModuleNotFoundError`, запустите `setup.ps1` и проверьте, что используется `.venv`.
- Если окно сразу закрывается, используйте `run_bot_debug.ps1` и прочитайте лог.
- Если HUD отображается, но не видит цвет, сначала проверьте привязку курсором (F3 для друида, Shift+F3 для лока) и цветовой индикатор в панели.
- Если цвет распознаётся, но клавиши не срабатывают, проверьте назначение соответствующих клавиш в игре, режим окна и уровень прав процесса.
- Если аддон выдаёт Lua-ошибки, включите отображение Lua-ошибок и проверьте, какая функция или строка указана первой в сообщении.
